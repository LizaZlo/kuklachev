# Установка и первый запуск

Один шаблон для всех: копируете с флешки, ставите зависимости, запускаете лендинг.  
**Git не обязателен** — для вёрстки достаточно VS Code, Node.js и папки проекта.

Кто хочет историю изменений и проверку кода перед коммитом — отдельно ставит Git и один раз выполняет `git init` у себя на диске (на флешке папки `.git` нет).

---

## Что нужно всем (обязательно)

### 1. Visual Studio Code

1. Скачать: [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Установить (галочка **Add to PATH** — оставить).
3. Открыть проект: **File → Open Folder** → папка `react-starter-template`.

Рекомендуемые расширения: **ESLint**, **Prettier**, **EditorConfig for VS Code**.

### 2. Node.js

1. Скачать **LTS** (версия **22.x**): [https://nodejs.org/](https://nodejs.org/)
2. Установить с настройками по умолчанию.
3. Перезапустить VS Code.

Проверка в терминале VS Code (**Terminal → New Terminal**):

```bash
node -v
npm -v
```

Должны отобразиться версии (Node не ниже 18, лучше 22).

### 3. Шаблон с флешки

1. Скопировать папку **`react-starter-template`** на диск (например `C:\projects\`).
2. На флешке **нет** папки `node_modules` и **нет** `.git` — так и должно быть.
3. Открыть скопированную папку в VS Code.

### 4. Первый запуск

В терминале, в корне проекта (где `package.json`):

```bash
npm install
npm start
```

- Сайт: [http://localhost:8080](http://localhost:8080)
- Остановка: **Ctrl+C** в терминале
- Сборка для сдачи: `npm run build` → папка **`dist`**

При `npm install` без Git может появиться предупреждение от **Husky** (`git command not found` или «not a Git repository») — **это нормально**, на работу сайта не влияет.

### Линтеры (для всех)

- На `npm start` и `npm run build` линтеры **не запускаются**.
- Проверить код вручную:

```bash
npm run lint
npm run stylelint
npm run lint:fix
npm run stylelint:fix
npm run format
```

### Сдача работы

- Архив папки проекта **или** только папка **`dist`** после `npm run build` (как скажет преподаватель).

### Чеклист (обязательный)

- [ ] VS Code установлен
- [ ] Node.js установлен, `node -v` работает
- [ ] Шаблон скопирован с флешки на диск
- [ ] `npm install` и `npm start` прошли успешно

## Git по желанию

**Кому подходит:** хотите коммиты, историю изменений и автопроверку перед `git commit`.

### Установить Git

**Git for Windows:** [https://git-scm.com/download/win](https://git-scm.com/download/win)  
При установке оставить опцию: Git доступен из командной строки.

Проверка:

```bash
git --version
```

### Подключить репозиторий у себя

В корне **уже скопированного** проекта (где `package.json`):

```bash
git init
```

Рекомендуемый порядок, если Git ставите **до** первого `npm install`:

1. Скопировать шаблон с флешки.
2. Установить Git.
3. `git init`
4. `npm install` — Husky подключит хук **pre-commit**.
5. `npm start`

Если вы уже сделали `npm install` **без** репозитория, после `git init` выполните:

```bash
npm run prepare
```

### Работа с версиями

```bash
git status
git add .
git commit -m "Описание изменений"
```

Перед коммитом Husky запускает **ESLint**, **Stylelint** и **Prettier** для изменённых файлов.  
Если коммит не проходит — исправьте ошибки или выполните:

```bash
npm run lint:fix
npm run stylelint:fix
npm run format
```

Один коммит без проверок (только если преподаватель разрешил):

```bash
git commit --no-verify
```

Отключить проверки перед коммитом навсегда: удалить файл `.husky/pre-commit` или убрать в нём строку `npx lint-staged`.

### Чеклист (если выбрали Git)

- [ ] Git установлен, `git --version` работает
- [ ] Выполнены `git init` и (при необходимости) `npm run prepare`
- [ ] Понимаете `git add` / `git commit` или знаете, куда смотреть в справке

## С Git и без — в чём разница

| | Только вёрстка | С Git (после `git init`) |
|---|----------------|---------------------------|
| Установка Git | Не нужна | Нужна |
| Репозиторий | Нет | Свой, у вас на диске |
| История изменений | Нет (только файлы) | Есть |
| Линтеры перед коммитом | Нет | Да (Husky) |
| Запуск лендинга | `npm start` | `npm start` |

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| `node` / `npm` не найдены | Переустановить Node.js, перезапустить VS Code |
| Долгий `npm install` | Нужен интернет; первый раз это нормально |
| Порт 8080 занят | Закрыть другой `npm start` или перезагрузить ПК |
| В консоли браузера `contentscript.js` | Расширение браузера, не ваш код — проверьте в инкогнито |
| Husky ругается при `npm install` | Без Git — игнорируйте; с Git — сначала `git init`, затем `npm install` или `npm run prepare` |
| Коммит не запускает линтеры | После `git init` выполнить `npm run prepare` |
